## What is CKA

The Certified Kubernetes Administrator (CKA) is a certification created by the Linux Foundation and the Cloud Native Computing Foundation.

It tests skills in:

- Cluster setup and management
- Pods and Deployments
- Services and Networking
- Storage
- Troubleshooting
- Security
